Every Dataset Begins With A Question

Before creating graphs and tables, researchers first collect reliable information. In this lesson, you will discover different methods of collecting data and learn how to choose appropriate ways of presenting information.

Your Data Journey

01

Collect Data

Learn how surveys, interviews, observations and experiments help gather information.

02

Organize Data

Arrange collected information using tables and frequency distributions.

03

Represent Data

Present information clearly using suitable graphs and charts.

Lesson Objectives

  • Identify different methods of collecting data.
  • Explain why accurate data collection is important.
  • Organize collected information into tables.
  • Select appropriate graphs to represent data.

Learning Through Discovery

This lesson follows a constructivist learning approach where learners actively collect, organize and interpret their own data instead of only memorising procedures.
